Prepared 2026-10-07 after Patrik approved the seventeen interview defaults.
This is a local preparation pack. No ChatGPT Project or connection has been created
or changed, and access from the target project has not been tested.

## Load the foundation

1. Create or use a ChatGPT Project for travel.
2. Copy the contents of [project instructions](chatgpt-project-instructions.md)
   into its project instructions.
3. Add [travel goals](../profile/travel-goals.md),
   [traveler profile](../profile/universal-traveler-profile.md), and
   [travel principles](../profile/travel-principles.md) as sources, or make their
   current versions readable through the connected GitHub repository.
4. Provide the [trip index](../trips/README.md), the relevant current trip brief,
   and its decision history through readable sources. Uploaded copies need refreshing
   after changes; loading preferences alone does not provide the current trip plan.

Projects share uploaded files, project instructions, and connected sources across
their chats. A ChatGPT Project does not automatically read this local checkout.
See [official project documentation](https://learn.chatgpt.com/docs/projects).
Connected-source availability depends on the matching plugin and account/workspace
settings; see [official prompting guidance](https://learn.chatgpt.com/docs/prompting).
Both pages were checked on 2026-10-07. These product facts do not verify Patrik's access.
