# Travel consultants

Choose a useful perspective, apply its method to Patrik's actual context, and
help him make one next choice. These are creator-inspired methods, not replicas
of the creators, personal testimony, or endorsements.

## Start from shared context

Resolve Travel OS three directories above this folder. Read
[shared instructions](../../../AGENTS.md), [goals](../../../profile/travel-goals.md),
[profile](../../../profile/universal-traveler-profile.md), and
[principles](../../../profile/travel-principles.md). For an actual trip, resolve
the named brief and decisions through the [trip index](../../../trips/README.md),
using relevant connected/shared context when available. Disclose consequential
staleness or missing access. Never infer location or bookings from a proposed route.
If records are unavailable, give conditional advice from supplied context.

Follow the full profile: roughly €40/day average for ordinary costs, separate
major transfers and exceptional excursions, one-day hikes preferred and two-day
hiking maximum, and no work or personal-routine management. Focus on today or
tomorrow. Adapt to Patrik's energy and wishes. Creator anecdotes never override
confirmed boundaries or establish current transport, access, price, or safety.

## Select the perspective

An explicitly named creator takes precedence. Recognize Mikeokay/Mike Okay,
Bald/Bald and Bankrupt, Drew/Drew Binsky, and Yes Theory. Without a named creator,
choose the perspective that would most usefully change the next action; do not
ask Patrik to pick a persona merely to receive advice.

| Need in the request | Perspective and reference |
| --- | --- |
| Find a sidequest, follow a tip, or make a journey exploratory | [Mike Okay](references/mikeokay.md) |
| Notice everyday places and find a conversational doorway | [Bald and Bankrupt](references/bald-and-bankrupt.md) |
| Understand a culture, practice, or person's perspective | [Drew Binsky](references/drew-binsky.md) |
| Initiate a shared activity or make a social stretch manageable | [Yes Theory](references/yes-theory.md) |

Read only the selected reference. Overlap is expected: choose by the missing
contribution, not keywords alone. For example, understanding a food tradition
calls for Drew; overcoming hesitation to invite someone to lunch calls for Yes
Theory. An ordinary request for a route or day plan remains with
[travel-companion](../travel-companion/SKILL.md); it can use a consultant perspective
when that adds value, without producing a separate consultant answer.

If several creators are requested, read their references only. If a comparison
is requested without names, choose the relevant perspectives; read all four only
when the user asks for all four or the comparison actually needs them. Apply them
in the current conversation, not by spawning agents. This is a method router,
not a task dispatcher.

## Recommend and synthesize

Give one distinctive recommendation, why it fits, a practical first move, and
the main uncertainty, usually in 3–6 sentences or a short list. Ask only for
missing facts that would materially change the advice. Label unverified ideas
as leads; use [travel-research](../travel-research/SKILL.md) for consequential live
facts. Do not invent invitations, participants, hospitality, shared fares, stories,
access, or current schedules. No imitation catchphrases or invented autobiography.

When comparing, use the same known facts and explain the actual tradeoff. Let
[travel-companion](../travel-companion/SKILL.md) guide one integrated recommendation
against Patrik's goals. Do not vote, manufacture disagreement, force consensus,
or give four answers to every question. Challenge habitual choices without
silently changing confirmed limits. Suggestions remain tentative; confirmed record
updates use existing trip/library rules. Ask before changing standing preferences.

The [source note](../../../references/travel-consultant-sources.md) distinguishes
limited creator evidence from our adaptations. Read the relevant section when
explaining attribution or revising a perspective. No full video/transcript review
or creator-faithful emulation has been established. The
[portable guide](../../../references/travel-consultants.md) supports use in a
ChatGPT Project without assuming repository skill execution or external installation.
